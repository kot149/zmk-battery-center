## Findings considered and rejected

Recorded so the next audit doesn't re-litigate them:

- **DateRangePicker timezone mismatch**: false positive — local-day
  boundaries compared as epoch ms is correct user-local date filtering.
- **`PRUNED_FILES` unbounded growth** (`history.rs:10`): one small entry per
  unique device file; negligible memory over any realistic lifetime.
- **Chart smoothing O(N·window)**: already mitigated by range-limited fetch
  (`BatteryHistoryChart.tsx:349-355`) and the `smoothedByKey` memo (line 415).
- **Missing CLAUDE.md/AGENTS.md**: false positive — both exist at repo root.
- **CSV formula injection via notification text**: requires the user to
  paste notification text into a spreadsheet; CSV write path is already
  sanitized (`ble.rs`, commit a431859). Not worth doing.
- **`fireAndForget` swallows errors silently**: false positive — it logs
  (`src/utils/common.ts`).
- **CI missing Playwright browser install**: false positive — present at
  `ci.yml:55`.
- **0% battery readings filtered from chart**: intentional (`BatteryHistoryChart.tsx:360,391`);
  worth at most an explanatory comment.
- **Tray icon sync on every device update / triple window reposition**
  (`App.tsx:113-124,255-267`): real but debounced/rare and cheap; the triple
  reposition is a deliberate platform-timing workaround. Not worth doing now.
- **tsconfig target drift (ES2020 vs e2e ES2022), bun 1.3.13 vs 1.3.14
  local/CI drift, missing .env.example**: cost below the noise floor.
- **`sudo` use inside install_mac.sh**: standard for /Applications installs;
  mitigated further by plan 002's checksum work.
- **CSP `img-src data:`**: images cannot execute script; React escapes
  by default and `dangerouslySetInnerHTML` is absent. Tighten
  opportunistically if ever touching tauri.conf.json.
